# 足彩六宫格截图

私有存档：每期 14 场 / 单场六宫格截图打包为 `.zip` 上传。

## 目录结构

按月份归集：

- `2026-08/` — 8 月各期 zip
- `2026-09/` — 9 月各期 zip

## 命名

- 包名：`{期号}.zip`（如 `26128.zip`）
- 图名：`{期号}{场次两位}.png`（如 `2612801.png` … `2612814.png`）

## 固定剔除公司

- 官方(胜平负) / 中国竞彩官方
- 澳*（澳彩）
- 香港马*
- 必*（必发）
- Germania Sport
- 另剔造成毛刺的公司，六宫格平滑后再截
